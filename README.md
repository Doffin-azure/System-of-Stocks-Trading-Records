# Stock Trading Record Analysis

A SUSTech STA321 course project that processes stock-trade records, estimates large-trade capital flows, and displays the resulting time series in a local web application.

## Explore the project

| Start here | What it contains |
| --- | --- |
| [Course report](report/STA321%20Project%20Report.pdf) | Data, method, and results |
| [Data preparation notebook](data_convert.ipynb) | Input conversion |
| [MapReduce code](代码/mapreduce/System-of-Stocks-Trading-Records/demo) | Java jobs for filtering and aggregating trades |
| [CSV visualization](代码/csv-visualization) | Spring Boot application for viewing results |

The MapReduce jobs and the web app are separate Maven projects. Start with the report to match the input data and output schema before running either module.
